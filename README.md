# Axiomatic

> **Интерактивный интерпретатор логики первого порядка (FOL) со схемами аксиом.**  
> Гибрид ITP и ATP с семантическими эвристиками, тактиками и полнотой.

## О проекте

**Axiomatic** — это интеллектуальный инструмент для работы с формальными теориями, объединяющий:

- **Интерактивный доказыватель теорем (ITP)** — вы управляете доказательством пошагово, применяя тактики.
- **Автоматический доказыватель (ATP)** — система сама ищет вывод на основе обратной резолюции и суперпозиции.

В отличие от классического Prolog (ограниченного хорновскими дизъюнктами), Axiomatic работает с **полным FOL со схемами аксиом** и обеспечивает **логическую полноту**.

### Ключевые особенности

- **Гибридный вывод** — комбинирует синтаксические стратегии (обратная резолюция, суперпозиция) с **семантическими эвристиками**, которые анализируют структуру аксиом и направляют поиск.
- **Полнота по FOL** — поддержка кванторов, предикатов, функций и схем аксиом.
- **Интерактивный интерпретатор** — вы видите результат сразу, можете добавлять пояснения к шагам, находить все X, для которых верно утверждение, и доказывать теоремы тактиками.
- **Работа с файлами**:
  - Загрузка аксиом и теорем из файлов.
  - Сохранение интерактивно написанных доказательств.
  - Проверка свойств теорий (например, является ли структура моноидом).
- **Расширяемость** — архитектура позволяет подключать новые логики (модальная — в планах).

### Планируемые возможности (Roadmap)

- [ ] Поиск конечной модели (и доказательство её отсутствия).
- [ ] Встроенный SMT/SAT-решатель.
- [ ] Расширение до модальной логики.
- [ ] Визуализация дерева доказательства.

## Установка

### Требования

- Rust 1.70 или выше
- Cargo

### Сборка из исходников

```bash
git clone https://github.com/ваш_логин/axiomatic.git
cd axiomatic
cargo build --release
```

Бинарник появится в `target/release/axiomatic`.

### Запуск

```bash
cargo run --release
```

Или после сборки:

```bash
./target/release/axiomatic
```
